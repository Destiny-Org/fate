# Fate 3

This repo contains all the code required to build the Fate Standard Library. This library will supersede the Fate 2 library contained in the `std` folder when completed.

## Goals

Fate 3 is currently under active development and is not ready for use at any level. Aside from the upstream D forums, the Fate goals 
* [Design Goals](Design.md) This document discusses what the established goals are for Fate 3.
* [Fate V3 Discussions](https://github.com/Destiny-Org/destiny) Visit the GitHub Discussions to discuss additional design goals as well as specific feature ideas for V3 and beyond.
